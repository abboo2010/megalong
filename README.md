# Megalong Shopping Mall website

Static site (HTML, CSS, vanilla JS). No build step.

- `index.html`, `style.css`, `app.js`: the page (Design 6 "Megalong Friendly")
- `common.js`: shared data and behaviour (stores, events, languages EN/BM/中文, saved list)
- `assets/`: images

All store, event, phone, hours and parking content is sample data. Edit the store list in `common.js` and the featured stores in `app.js` (`FEATURED`).

Deploy: connect this repo to Netlify, no build command, publish directory `/`.
